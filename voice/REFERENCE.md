# Как записать свой голос для озвучки

Сайт умеет играть **готовые аудиофайлы** (папка `audio/<slot>.mp3`) вместо синтеза.
Голос — твой: при помощи GPT-SoVITS (клонирование по референсу) или просто диктокта вручную.

## Что нужно для GPT-SoVITS: один «референс» (эталон) голоса

Склонировать голос можно с одного чистого ролика 30–120 секунд. Запиши его так:

1. **Тихо.** Комната без шума: без музыки, без улицы, без эха. Микрофон на 20–30 см.
2. **Натуральный темп** — как рассказываешь ребёнку урок, чуть медленнее обычного, без «дикторской» интонации.
3. **Читай связный русский текст**, примерно 300–500 символов. Лучше всего — готовые человеческие объяснения из `voice/texts.json` (там 18 правил). Прочитай 3–4 из них подряд.
4. **Один голос.** Никаких второго человека, смеха, шёпота в кадре.
5. **Формат:** WAV или MP3, 44.1 кГц моно (или любой, ffmpeg приведёт). Файл `mic-voice.wav`.

GPT-SoVITS дополнительно попросит:
- короткий чистый кусок 5–15 секунд (самое чёткое предложение из записи) + его точный текст — для быстрой проверки синтеза;
- полный текст всей записи — для лучшего качества.

## Быстрый ручной вариант (вообще без моделей)

Иногда проще продиктовать 18 главных текстов самому (`*_human` из `voice/texts.json`),
порезать в Audacity на файлы `audio/<ruleId>_human.mp3` и перезапустить `node tools/gen-manifest.js`.
Остальные слоты продолжат говорить синтезом. Менять файлы можно в любой момент.

## Глоссарий слотов

- `<ruleId>_human` — правило человеческим языком (крупная карточка).
- `<ruleId>_textbook` — формулировка из учебника (родительский блок).
- `<ruleId>_ex0..exN` — примеры (каждая строчка списка).

Их полный список с текстами — в `voice/texts.json` (генерится `node tools/dump-texts.js`).
