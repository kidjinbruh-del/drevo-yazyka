# Озвучка: какой голос и чем он сделан

## Текущий голос: Microsoft Svetlana (нейросетевой)

Озвучка в `audio/` сделана нейросетевым голосом **ru-RU-SvetlanaNeural**
(теги Friendly, Positive — тёплый и доброжелательный). Раньше здесь был
системный голос **Microsoft Irina** из SAPI: он ровный, но звучит
роботом, и ребёнку слушать его тяжело. Новые файлы при этом ещё и легче
старых: 2,86 МБ против 3,97 МБ на те же 36 дорожек.

Других русских женских нейросетевых голосов в edge-tts сейчас два
(второй — Дмитрий, мужской), поэтому выбора нет: Светлана — лучший из
доступных женских.

## Как перегенерировать

```powershell
python -m pip install edge-tts
python voice\check-stress.py          # ударения: покрытие и опечатки
python voice\tts-text.py              # посмотреть, как текст станет речью
python voice\gen-edge.py --app-only   # 36 дорожек приложения
node tools\gen-manifest.js            # обновить манифест js/audio.js
```

Файлы кладутся в `voice/samples/<голос>/`. Скопировать оттуда в `audio/`
с дефисом в идентификаторе (в `audio/` он нужен, в `res/raw/` — нет, его
ставит `tools\sync-audio.ps1`).

**Темп и высота задаются параметрами скрипта.** Сейчас `-8%` и `+2Hz`:
объяснение правила читают вслух, спешка тут неуместна. Если голос кажется
слишком быстрым или слишком высоким — поменяйте `--rate`/`--pitch` и
перегенерируйте, это две минуты работы.

Сравнить варианты можно в `voice/compare/`: старый системный голос, новый
без ударений и новый с ударениями.

## Текст для синтеза ≠ текст на экране

`voice/tts-text.py` — слой между текстом правила и голосом. На экране
«33 буквы», «ъ и ь», «твёрдый знак после согласной»: коротко и понятно
глазу. В озвучке те же места разворачиваются в речь:

| на экране | в озвучке |
|-----------|-----------|
| 33 буквы | тридцать три бу́квы |
| ъ и ь | твёрдый знак и мя́гкий знак |
| алфавит | алфави́т — ударение из словаря |
| конец слова | пауза перед «а», «но», «потому что» |

Экранный текст при этом не меняется: ударения и развёрнутые знаки есть
только в озвучке.

**Словарь ударений — `voice/stress-ru.txt`, 465 слов.** Нужен из-за
омографов: без него «вода» и «водный» читаются одинаково. Служебные
слова (это, этот, если, или) сознательно не размечены: собственного
ударения у них нет, а знак только сбивает голос.

`voice/check-stress.py` проверяет словарь без синтеза: знак над гласной,
нет ли латиницы (частая беда — «ó» вместо русской «о́») и, главное, что
каждое многосложное слово из `voice/texts.json` размечено. Пропущенное
слово не сломается, но останется прочитанным как догадается нейросеть,
и это тихо портит качество.

## Путь «своим голосом» (GPT-SoVITS)

Если захочется озвучить правила твоим голосом — прежний рецепт со всеми
шагами ниже. Он работает и сейчас, но требует Python 3.9–3.11 и ~2 ГБ
моделей.

# Озвучка твоим голосом: конвейер

Сайт вставляет твой голос через папку `audio/`. Кнопки «▶» на правилах и примерах
играют `audio/<slot>.mp3`, **если файл есть**; если нет — честный синтез (Web Speech, ru).

Слоты: `{ruleId}_human`, `{ruleId}_textbook`, `{ruleId}_ex0…`. Манифест из реальных
файлов собирает `node tools/gen-manifest.js` → `js/audio.js`.

## Шаг 1. Запиши эталон голоса

Прочти `REFERENCE.md` — одна запись 30–120 сек, тихо, натурально.

## Шаг 2. Установи GPT-SoVITS (нужен Python 3.9–3.11! Не 3.14)

Этот ПК сейчас на Python 3.14 — GPT-SoVITS с ним не собирается. Поставь рядом 3.11:

```
winget install Python.Python.3.11
```

В новом терминале:

```
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Затем запусти WebUI (`python webui.py en` или через `go-webui.bat`) и следуй его
шагам: загрузи предобученные модели (скачаются с HuggingFace, ~2 ГБ), открой вкладку
«Инференц» → загрузи `mic-voice.wav` + его текст → проверь синтез одной фразой.

**Важное про русский:** базовые модели GPT-SoVITS натренированы в основном на
китайском/английском/японском и др. Русский работает «из-под текста» и после
обкатки обычно звучит нормально, но не гарантированно идеально (ударения могут
плыть). Перед генерацией всех 54 слотов обязательно попробуй одну фразу из `texts.json`
и послушай. Если качество не устраивает — быстрый и надёжный русский запасной
вариант: **F5-TTS** (`pip install f5-tts`, MIT), там русский родной и качество выше.

## Шаг 3. Настрой пресет голоса и передай его скрипту

В WebUI GPT-SoVITS: вкладка «推理服务配置» (Inference config) → сохрани свой эталон
как пресет голоса и запомни его имя. Запусти OpenAI-совместимый сервер (api_v2).

## Шаг 4. Сгенерируй все озвучки

```
$env:GPT_SOVITS_VOICE = "<имя-пресета-голоса>"
node voice\gen-gptsovits.mjs        # лентяйка пройдёт по всем 54 слотам
node tools\gen-manifest.js          # обновить манифест js/audio.js
```

## Шаг 5. Обнови сайт

1. Проверь локально через `file://`: открой правило, нажми ▶ — должен звучать твой голос.
2. Коммит и пуш — GitHub Pages раздаст аудиофайлы, сайт станет «говорить тобой».

## Без GPT-SoVITS (другой путь)

Тот же `audio/` можно заполнить просто диктофоном и Audacity — см. `REFERENCE.md`,
раздел «Быстрый ручной вариант». Манифест и сайт не меняются: «файл есть → играем файл».
