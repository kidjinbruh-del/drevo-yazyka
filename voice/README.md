# Озвучка твоим голосом: конвейер

Сайт вставляет твой голос через папку `audio/`. Кнопки «▶» на правилах и примерах
играют `audio/<slot>.mp3`, **если файл есть**; если нет — честный синтез (Web Speech, ru).

Слоты: `{ruleId}_human`, `{ruleId}_textbook`, `{ruleId}_ex0…`. Манифест из реальных
файлов собирает `node tools/gen-manifest.js` → `js/audio.js`.

## Шаг 1. Запиши эталон голоса

Прочти `REFERENCE.md` — одна запись 30–120 сек, тихо, натурально.

## Шаг 2. Установи GPT-SoVITS (нужен Python 3.9–3.11! Не 3.14)

Этот ПК сейчас на Python 3.14 — GPT-SoVITS с ним не собирается. Поставь рядом 3.11:

```
winget install Python.Python.3.11
```

В новом терминале:

```
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Затем запусти WebUI (`python webui.py en` или через `go-webui.bat`) и следуй его
шагам: загрузи предобученные модели (скачаются с HuggingFace, ~2 ГБ), открой вкладку
«Инференц» → загрузи `mic-voice.wav` + его текст → проверь синтез одной фразой.

**Важное про русский:** базовые модели GPT-SoVITS натренированы в основном на
китайском/английском/японском и др. Русский работает «из-под текста» и после
обкатки обычно звучит нормально, но не гарантированно идеально (ударения могут
плыть). Перед генерацией всех 54 слотов обязательно попробуй одну фразу из `texts.json`
и послушай. Если качество не устраивает — быстрый и надёжный русский запасной
вариант: **F5-TTS** (`pip install f5-tts`, MIT), там русский родной и качество выше.

## Шаг 3. Настрой пресет голоса и передай его скрипту

В WebUI GPT-SoVITS: вкладка «推理服务配置» (Inference config) → сохрани свой эталон
как пресет голоса и запомни его имя. Запусти OpenAI-совместимый сервер (api_v2).

## Шаг 4. Сгенерируй все озвучки

```
$env:GPT_SOVITS_VOICE = "<имя-пресета-голоса>"
node voice\gen-gptsovits.mjs        # лентяйка пройдёт по всем 54 слотам
node tools\gen-manifest.js          # обновить манифест js/audio.js
```

## Шаг 5. Обнови сайт

1. Проверь локально через `file://`: открой правило, нажми ▶ — должен звучать твой голос.
2. Коммит и пуш — GitHub Pages раздаст аудиофайлы, сайт станет «говорить тобой».

## Без GPT-SoVITS (другой путь)

Тот же `audio/` можно заполнить просто диктофоном и Audacity — см. `REFERENCE.md`,
раздел «Быстрый ручной вариант». Манифест и сайт не меняются: «файл есть → играем файл».

## Вспомогательные команды

```
node tools\dump-texts.js            # обновить voice/texts.json (тексты для записи)
node tools\gen-manifest.js          # обновить js/audio.js по наличию файлов
powershell -File tools\gen-audio.ps1 # bridge: заполнить human/textbook голосом Microsoft Irina
```
