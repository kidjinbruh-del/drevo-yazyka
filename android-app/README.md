# Древо языка — приложение для Android

Телефонная версия «Древа языка»: те же 18 правил, та же озвучка, тот же тренажёр —
но с оболочкой приложения вместо сайта.

## Что добавилось по сравнению с сайтом

- **Нижняя панель вкладок** вместо верхнего меню: большой targets, ничего не мельчит.
- **Тёмная тема** с переключателем «как в системе / тёмная / светлая». Выбор
  сохраняется и применяется до первой отрисовки — страница не мигает.
- **Статус-бар в тон теме**: цвет берётся из той же палитры, что и фон.
- **«Поделиться деревом»** — кнопка в шапке выгружает прогресс в JSON и отдаёт
  файл через системное «Поделиться». На странице родителя рядом появляется
  обратная кнопка: загрузить своё дерево из файла.
- **Ни одного разрешения на интернет**: озвучка лежит внутри приложения,
  синхронизации нет. Ни аккаунтов, ни рекламы, ни аналитики.

Оформление — слой `css/app.css` поверх сайтового `css/style.css`: палитра «лес
вечером», скругления, крупные кнопки, безопасные зоны под системными панелями.

## Сборка

```powershell
cd android-app
npm install
powershell -ExecutionPolicy Bypass -File tools\sync.ps1   # копирует сайт в www + cap sync
$env:JAVA_HOME = "путь к JDK 21"
.\android\gradlew.bat -p android :app:assembleRelease
```

Подпись: `android-app/keystore.properties` (в git не попадает) + `drevo-yazyka.jks`.
Оба файла нужно хранить копией вне репозитория — без них обновление поверх
установленного приложения будет невозможно.

## Структура

- `www/` — копия сайта, её собирает `tools/sync.ps1` (в git не хранится)
- `capacitor.config.json` — appId `ru.drevo.yazyka`
- `tools/sync.ps1` — синхронизация сайта с нативным проектом
- `../css/app.css`, `../js/app.js` — слой приложения в самом сайте, поэтому
  браузерная версия получает то же оформление

## Требования

Android 5.1 и выше. Google Play Services не нужны. Установка APK ставится обычным
способом: включить «Неизвестные источники» для файлового менеджера и открыть файл.
