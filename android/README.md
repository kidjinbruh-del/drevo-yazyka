# Древо языка — Android (Kotlin + Compose)

Нативное приложение. До него была веб-версия в обёртке Capacitor (`../android-app`),
она осталась в репозитории как история версии 1.0.0, но собирается уже не она.

## Что внутри

| Слой | Файлы | Решение |
|------|-------|---------|
| Правила | `data/Rules.kt` | Сгенерирован из `../RULES.json` скриптом `../tools/gen-rules-kotlin.js`. Правьте JSON, а не Kotlin. |
| Прогресс | `data/Progress.kt` | `SharedPreferences` + `StateFlow`. Без базы: данных мало, синхронизации нет. |
| Озвучка | `audio/Narrator.kt` | `SoundPool` по mp3 из `res/raw`. |
| Темы | `ui/theme/Theme.kt` | Палитра «лес вечером», светлая и тёмная написаны отдельно. |
| Экраны | `ui/*.kt` | Дерево, список правил, паспорт правила, тренажёр, страница родителя. |

Дерево рисуется на `Canvas` по кривым Безье: листья раскладываются по кривым,
поэтому дерево остаётся пропорциональным на любом экране, а «собранный» лист
меняет вид мгновенно.

## Сборка

Нужен JDK 21 и Android SDK 35.

```powershell
# 1. данные и озвучка -> код и ресурсы
& ..\tools\sync-audio.ps1
node ..\tools\gen-rules-kotlin.js

# 2. APK
$env:JAVA_HOME = "<путь к JDK 21>"
.\gradlew.bat :app:assembleRelease     # подписанный
.\gradlew.bat :app:test               # проверки целостности правил
```

Подпись берётся из `android/keystore.properties` (в репозитории его нет).
APK: `app/build/outputs/apk/release/app-release.apk`.

## Проверки

`app/src/test/java/ru/drevo/yazyka/RulesTest.kt` ловит случай, когда генератор
отработал на неполных данных: пустые паспорта, задания без верного ответа,
ссылки на несуществующие правила.

## Чего в приложении нет

Интернет-разрешения нет в манифесте намеренно: озвучка лежит внутри, данные
не уходят никуда. Нет аккаунтов, аналитики и Google Play Services.
