# Древо языка — спецификация проекта (для передачи другому ИИ)

## 1. Суть

Статический детский сайт (1–3 класс) по русскому языку. Каждое правило учебника переведено на «человеческий язык», озвучивается и отрабатывается тренажёром. Прогресс ребёнка — **личное дерево**: каждое пройденное правило прорастает листиком на SVG-дереве. Есть страница для родителей: «переводчик с учебникового», мини-курс и печатная шпаргалка «учебник → дома».

Девиз проекта: «Древо языка — то, чего не объяснили в учебнике».

## 2. Жёсткие правила архитектуры (философия)

- **Ноль зависимостей, ноль сборки**: ни npm, ни webpack, ни внешних CDN. Всё открывается через `file://` и работает офлайн.
- **Никаких эмодзи в UI** — только встроенный SVG-набор иконок.
- **Никакого i18n**: контент только на русском (есть тест, который это проверяет).
- **`js/data.js` — единственный источник истины.** `RULES.json` — авто-экспорт той же структуры; тест `check-sync.js` гарантирует полное совпадение.
- Человеческий язык вместо канцелярита: rule.human ≤ ~300 символов, без терминологической ватты.
- Ребёнок не зубрит формулировку — он применяет правило на тренажёре.
- Правила связаны графом «выросло из» → русский язык выглядит системой, а не списком.
- Анимации только на `transform`/`opacity`, уважается `prefers-reduced-motion`.
- Критерий успеха каждого правила: «показать ребёнку 7–9 лет — если сказал „о, так понятно“, всё правильно».

## 3. Технологии

Чистые HTML + CSS (один файл `css/style.css`) + ванильный JS (IIFE с глобальными объектами, старый стиль ES5, `"use strict"`). SVG — «вручную». Web Speech API для озвучки. localStorage для прогресса. Тесты — на чистом Node (vm, без зависимостей).

Открытие: любые страницы через `file://` или через хостинг (GitHub Pages). Порядок подключения скриптов строгий — см. секцию 9.

## 5. Модель данных правила (поле `rule`, объект в `rulesData.rules[]`)

```jsonc
{
  "id": "g3-members",     // формат: g{grade}-{slug}
  "grade": 3,             // 1 | 2 | 3 (класс = ветка дерева)
  "branch": "ветви",      // метафора: корни (1) | ствол (2) | ветви (3)
  "title": "Главные члены предложения",
  "human":    "…",        // правило человеческим языком (озвучивается, ≤ ~300 зн.)
  "textbook": "…",        // формулировка из учебника (канцелярит, для родителя)
  "examples": ["…", "…"], // живые примеры с пояснением
  "wrong": { "text": "…как думают ошибочно…", "why": "…почему это не так…" },
  "errors":  ["…", "…"],  // типичные школьные ошибки
  "links":   ["g1-sentence", "g2-noun"],  // id правил, «из которых это выросло»
  "quiz": [ … вопросы, см. ниже … ]
}
```

### Вопросы тренажёра (`rule.quiz[]`)

- **choice** — выбор одного из вариантов:
  ```jsonc
  { "type": "choice", "q": "…", "options": [
      { "t": "облака", "ok": true,  "why": "…что? облака…" },
      { "t": "плывут", "ok": false, "why": "…это сказуемое…" }
  ] }
  ```
  Ровно один `ok`. `why` показывается в ответе после клика в любом случае.
- **tap** — кликать по словам-токенам по порядку:
  ```jsonc
  { "type": "tap", "q": "Покажи сначала подлежащее, потом сказуемое.",
    "tokens": ["Солнышко", "светит", "ярко", "."],
    "steps": [
      { "i": 0, "mark": "подлежащее", "why": "что? — Солнышко." },
      { "i": 1, "mark": "сказуемое", "why": "что делает? — светит." }
    ] }
  ```
  `mark` — подпись шага («Шаг 1: подлежащее»), `why` — пояснение после правильного клика. Токен `","` (запятая) — псевдо-токен `data-punc`, некликабельный. Означиваются токены только по возрастанию `steps[]`.

Требования тестов к данным: id уникальны, `grade` 1–3, веток 6/5/7 шт., у question ровно один `ok` (choice), внутри каждого правила первый шаг tap-вопроса — `i:0`, все `steps[].i` валидны.

### Поле `translations` (14 пар)

```jsonc
{ "from": "Основу предложения составляют главные члены",
  "to":   "Основа — это подлежащее и сказуемое. Без них предложение рассыплется…",
  "ruleId": "g3-members" }   // link на правило для кнопки «Открыть правило»
```

## 6. Текущая база данных (18 правил, 14 переводов)

- **1 класс — ветка «корни» (6):** g1-sounds Звуки и буквы · g1-vow Гласные и согласные · g1-voiced Звонкие и глухие согласные · g1-syllable Слоги · g1-stress Ударение · g1-sentence Предложение

- **3 класс — ветка «ветви» (7):** g3-members Главные члены предложения · g3-pairs Парные согласные · g3-silent Непроизносимые согласные · g3-marks Мягкий и твёрдый знаки · g3-names Имена собственные · g3-comma Однородные члены и запятая · g3-others Местоимение, числительное и предлог

## 7. Страницы и их data-хуки

Общее для всех страниц: шапка `.site-header` с `.nav` (бренд + 4 ссылки `.nav-link` + селект `.grade-pad select[data-grade-select]`) и `.footer`. Скрипты подключаются в фиксированном порядке (секция 9).

### index.html
- `[data-total]`, `[data-total-text]`, `.tree-stats-num` — счётчики «N правил», «выросло X из Y».
- `[data-tree]` — контейнер личного дерева (SVG рисует Progress.tree).
- `[data-progress-bar]` — прогресс-бар (ширина %).
- `[data-grade-trigger]`, `[data-grade-chips]` — секция «С какого класса начнём» (чипы 1/2/3 класс); при первом заходе (нет класса) авто-скролл к ней.
- `[data-branches]` — карточки веток `.branch-card` (ссылка `rules.html?grade=N`).
- `[data-ach]`, `<template data-ach-tpl>` — сетка достижений.

### rules.html
- `[data-chips]` — чипы «Все / 1 класс / 2 класс / 3 класс».
- `[data-search]` — живой поиск по `title+human+textbook` (lowercase, ё→е не делается — просто toLowerCase).
- `[data-rules-grid]` — карточки `.rule-card` → `rule.html?id=…`, класс `learned` если пройдено.

### rule.html (паспорт правила)
- `[data-rule]` — корневой блок (JS читает `?id=`).
- `[data-rule-badge]` — badge «N класс · ветка» + класс `g{grade}`.
- `[data-rule-title]`, `[data-rule-human]` + `[data-rule-speak]` (кнопка озвучки).
- `<details>` «Так это написано в учебнике»: `[data-tb-speak]`, `[data-rule-textbook]`.
- `[data-rule-examples]` — список примеров с кнопками `listen-btn`.
- `[data-rule-wrong]` — «так нельзя» (text + why).
- `[data-rule-errors]` — ошибки со значком ✕ (CSS ::before).
- `[data-rule-links]` — «Откуда выросло» (чипы `.sibling-chip`), `[data-rule-next]` — «Что дальше».
- `[data-trainer]` — встроенный тренажёр; `[data-learned-note]` — «Листик вырос!».

### quiz.html
- `[data-quiz-select]` — селект «Любой класс / 1-2-3 класс»; `[data-quiz-grade]` — заголовок.
- `[data-quiz]` → `[data-quiz-meta]` (строка «Выбрано N вопросов из M правил»), `[data-quiz-trainer]` (место Trainer), итог `[data-quiz-result]` (`[data-qr-title]`, `[data-qr-score]`, кнопка «Ещё раз»).

### parent.html
- `[data-tr-form]` + `[data-tr-input]` + `[data-tr-out]` — переводчик.
- `.howto` — готовый мини-курс «Как объяснить „главные члены“ за 5 минут» (статический текст в HTML!).
- `[data-cheatsheet]` — таблица шпаргалки «Правило | Так в учебнике | Так дома» (генерится из RULES).
- `[data-print]` — кнопка `window.print()`.

## 8. Глобальные объекты (порядок подключения важен)

Скрипты на каждой странице в этом порядке:
`data.js → icons.js → voice.js → progress.js → trainer.js → main.js → <страничный скрипт>`

- **`window.RULES`**, **`window.TRANSLATIONS`** — данные (из `data.js`; там `window.RULES = rulesData.rules` с guard `typeof window`). `RULES.json` — экспорт для внешних инструментов.
- **`ICON`** (`icons.js`): `ICON.svg(name, cls)`, `ICON.render(name, cls)`, `ICON.scan(root)` — превращает `<i data-ic="name">` в inline SVG. Набор: speaker, check, close, arrowR, chevR, leaf, search, printer, book, home, play, star, grow, refresh.
- **`Voice`** (`voice.js`): `Voice.supported`, `Voice.speak(text)` (ставит в очередь, режет по `;\n`), `Voice.stop()`. Выбирает русский голос ОС (`ru-RU`, fallback `ru…`), rate 0.95, pitch 1.05. Офлайн.
- **`Progress`** (`progress.js`): ключ localStorage `drevo_state_v1` = `{grade, seen:{}, ach:{}}`.
  - `grade()`, `setGrade(g)` (1–3), `learned()`, `learnedByGrade(g)`, `learnedCount()`, `total()`, `isLearned(id)`, `markLearned(id)` → `{new:bool,[rule]}`, `reset()`.
  - `tree(rootEl)` — рисует SVG личного дерева, возвращает `{refresh():number}` (перекрашивает листья, возвращает кол-во «on»).
  - `ach()` — список достижений с флагом `got`. `toast(msg)` — всплывающее сообщение снизу.
- **`Trainer`** (`trainer.js`): `Trainer.mount(root, quizArr, {onDone(score,total), onAnswer(correct)})` → `{reset}`. Рисует по одному вопросу, «Дальше», итоговый блок `.tr-result`. Внутри: `renderChoice` / `renderTap`. Очко: choice — если клик по `ok`; tap — когда пройдены ВСЕ шаги (одно очко за вопрос). Неверный клик в tap — «тряска» (класс `shake`).
- **`DrevoHelpers`** (`main.js`): `ready(fn)`, `gradeLabel(g)`, `speak(text)`, `bindSpeak(root)`. Также на `ready`: `ICON.scan()`, подсветка активного пункта nav, наполнение `[data-grade-select]`, reveal-анимации `.rv` через IntersectionObserver (порог 0.15).

Компонентные события: смена класса `window.dispatchEvent(new CustomEvent("drevo:grade", {detail:g}))`.

## 9. Потоки взаимодействия

**Пройти правило** (rule.html): прочитал human (кнопка ▶ озвучит) → открыл «что в учебнике» → примеры (каждый озвучивается) → «так нельзя»/«Где ошибаются» → тренажёр в сайдбаре → в `onDone`: `Progress.markLearned(id)`; если «новый» — показать `.learned-note` и toast «Листик вырос! На дереве уже N …». Изменение дерева на главной видно при её следующем открытии (`Progress.tree` рендерится заново).

**Достижения** (прогресс-пороги): первый листик (1), «Пятак листьев» (5), «Десяток» (10), «Пышная крона» (все 18), «Целая ветка» (весь класс). Проверка в `checkAchievements` при `markLearned`; toast + `state.ach` сохраняются. Повторное прохождение правил достижений не даёт (только первый раз).

**Тренировка** (quiz.html): собирает все вопросы правил выбранного класса → перемешивает → берёт 8 → `Trainer.mount` → итог с процентом и вердиктом; «Ещё раз» перезапускает. Вопросы из разных правил идут вперемешку (метаданные о правиле не выводятся).

**Переводчик** (parent.js): нормализация (lowercase, ё→е, схлопывание пробелов), скоринг: `+3` если наш запрос внутри пары, `+5` если пара целиком внутри запроса, `+1` за каждое слово >4 букв, совпавшее в паре; сортировка по убыванию, топ-3 в `[data-tr-out]`.

## 10. localStorage

- `drevo_state_v1` — `{grade: 0|1|2|3, seen: {ruleId:true}, ach: {id:true}}`. Хранится весь объект.
- `drevo_sub_v1` — зарезервирован (не используется, документирован для будущего).
- Сброс только через `Progress.reset()` (вручную: localStorage.removeItem('drevo_state_v1')).
- Профиль/несколько детей НЕ поддерживается — один ребёнок на устройство (точка расширения).

## 11. Голос

`Voice.speak(text)`:
- `speechSynthesis` из ОС; голос — первый `ru-RU`, иначе `ru`, иначе `null` (null → системный). `onvoiceschanged` перезапрашивает голоса (Chrome подгружает их асинхронно).
- Текст режется по `[;\n]`, куски триммируются от `*`, `—`, и пунктуации по краям; читаются последовательно (очередь `.shift()`).
- `cancel()` ставит приоритет: новое «скази» скипает предыдущее.

## 12. Личное дерево (SVG, геометрия)

`Progress.tree(rootEl)` — один `<svg viewBox="0 0 440 372">`:
- земля: путь-поляна `M60,352 Q210,356 380,350` (stroke `#9ccc65`, 6).
- ствол: `M210,352 Q214,300 210,258` (`#6d4c41`, 16) + утолщение сверху.
- 3 ветви-кривые Безье (`#8d6e63`, 7): для класса 1 влево, 2 — вертикально вверх, 3 — вправо.
- 18 листьев `<g class="leaf [on]">` по фиксированным траекториям `traces` (6, 5, 7 точек) с эллипсом `rx=17 ry=11` класса `.leaf-shape`; невыученный — штриховой контур `#b8c2a8` (dasharray 5 3), выученный — заливка `#6fbe6a` + анимация `leaf-in` (scale из 0.3). Транслейт в `transform=translate(x,y)`, сам эллипс — внутри группы (фикс с `transform-box: fill-box`).
- подписи `.tree-label` «1/2/3 класс» по позициям `labels`.
- возвращает `{refresh()}` для перекраски без пересоздания.

**Единственный жёсткий CSS-fix-кейс:** анимация листа должна идти на `.leaf-shape`, а не на `.leaf`, иначе translate ветки затирается (см. комментарий в css).

## 13. Визуальный стиль (для визуальной оценки)

### Палитра (CSS `:root`)
- Фон «тёплая бумага»: `--paper #f7f4ec`, карточки `--paper2 #fffdf6`; радиал-градиенты (чис лимонный сверху-справа, бледно-зелёный слева).
- Чернила: `--ink #22301f`, `--ink-soft #4b5a46`, `--ink-faint #7c8a75`.
- Зелень (акцент/рост): `--green #3d8b40`, deep `#2c6b2f`, pale `#e5f1e3`; прогресс-градиент `green → #8cc63f`.
- Кора (ствол/ветки): `#6d4c41 / #5d4037` (SVG) и `--bark`-токены.
- Ягода (ошибки/«не так»): `--berry #c05a4e`, pale `#f9e6e2`.
- Солнце (доп. кнопка): `--sun #ef9c3b`.
- Баджи классов: g1 жёлто-салатный `#e8f0c9/#5b6b1f`, g2 песочный `#f9e8c8/#8a5a12`, g3 голубой `#e4e9f6/#3c5399`.

### Типографика
- Шрифт: `"Rubik", "Segoe UI", system-ui…`; размер тела 19px, межстрочный 1.65.
- Заголовки крупные и «дышащие»: h1 `clamp(34px,6vw,58px)`, lead `clamp(26px,4vw,40px)`, human-правило `clamp(23px,3vw,30px)` и жирное — читается ребёнком.
- Секции: заголовки `clamp(26px,3.6vw,38px)`.

### Геометрия
- Радиусы: карточки 20px, кнопки 14px, чипы — pill (999px), панель дерева 24px.
- Тени мягкие: `0 8px 24px rgba(47,62,41,.10)`, ховер-подъём translateY(-3px).
- Сетки: `repeat(auto-fit, minmax(280px,1fr))` (ветки), `minmax(300px,1fr)` (правила), `repeat(auto-fill,minmax(190px,1fr))` (достижения), hero `5fr/6fr`, паспорт правила `7fr/5fr`.
- Шапка sticky с blur «под бумагой»; на ≤900px сетки схлопываются в 1 колонку, nav-ссылки уходят в отдельный ряд.

### Компоненты-фишки
- Токены-слова тренажёра tap: крупный шрифт, рамка 2px, ховер → зелёная рамка; правильный клик заливает зелёным; запятая — без рамки, некликабельна.
- Ошибка в choice: кнопка краснеет, верный вариант подсвечивается зелёным, ниже причина.
- Wrong-блок «так нельзя» — бледно-ягодная карточка.
- Достижения: полупрозрачные (opacity .45), «полученное» — зелёная рамка.
- Progress-bar под деревом: дорожка 10px, заливка с градиентом, `transition: width .6s`.
- Toast — тёмно-зелёная капсула снизу по центру.
- Reveal-анимация `.rv` при скролле через IntersectionObserver.
- Печать (`@media print`): скрывается шапка/кнопки, шпаргалка уплотняется.

## 14. Тесты (Node, без зависимостей)

`node tests/run-all.js` гоняет 7 проверок (по порядку):
1. `build-data.js` — пишет `RULES.json` из `js/data.js`; печатает счётчики.
2. `check-data.js` — 18 правил (6/5/7), уникальность id, поля обязательны, quiz корректно (choice-ровно-1-ok, tap-steps валидны, первый шаг `i:0`).

## 16. Точки расширения (если «другие функционалы»)

- **Несколько детей / профили** — `drevo_sub_v1` уже зарезервирован для `{sub, profile, …}`; перенести ключ на `drevo_<profile>_v1`, дать переключатель в шапке.

- **PWA/i18n** — сознательно не заложены (философия: файл открывается с диска).
- **Дизайнер-пасс** — svg дерева и шпаргалка — кандидаты на отдельные макеты; палитра и токены готовы (см. секцию 13).
