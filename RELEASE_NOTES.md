# Древо языка 1.1.0 — нативное приложение

Приложение переписано на Kotlin и Jetpack Compose. До этого телефонная
версия была веб-страницей в обёртке Capacitor.

## Почему переписали

Обёртка работала, но у неё были потолок, за который не заглянуть:

- **озвучка зависела от системного голоса браузера** — на одном телефоне
  объяснение читало правильно, на другомpronounce-каша; теперь 36 mp3 лежат
  внутри APK и звучат одинаково везде;
- **дерево было картинкой с наложенными зонами клика** — при смене шрифта
  или повороте экрана зоны разъезжались с листьями;
- **прогресс жил в localStorage WebView**, а не в данных приложения: файл
  прогресса приходилось готовить вручную.

## Что изменилось

- **Дерево рисуется на `Canvas`** по кривым Безье: пропорционально на любом
  экране, листья нажимаются — открывается нужное правило. Раскладка листьев
  считается одной функцией и для рисования, и для проверки тапа, так что
  картинка и «живая» область не могут разойтись.
- **Прогресс в `SharedPreferences`**, выгрузка файла — через системный
  диалог, кнопка «Поделиться» отдаёт JSON с флагом на всё дерево.
- **Ни одного разрешения на интернет** в манифесте: озвучка внутри, данные
  никуда не уходят.
- **Палитра «лес вечером»**: тёмная и светлая темы написаны отдельно, а не
  вывернуты одна из другой.
- **Переводчик с учебникового** на странице родителя: кроме точного совпадения
  показывает похожее правило, если формулировка пересказана своими словами.
- **Тренажёр**: «выбери правильное» и «кликни слово». Во втором режиме после
  проверки видно, какие токены верные, а какие ребёнок отметил зря.
- **Аудитория приложения**: нижняя панель из четырёх вкладок, крупные цели для
  пальца, крупные отступы.

## Проверки

- 8 модульных тестов на целостность правил: паспорта не пустые, в каждом
  задании ровно один верный ответ, индексы токенов в границах, ссылки на
  правила существуют, обе дорожки озвучки на месте.
- Тест на дорожки добавлен после того, как сборка с `shrinkResources` молча
  вырезала все 36 mp3: APK собирался, а кнопка «Послушать» молчала.
  Теперь это ловится на сборке.

## Известные ограничения

- `android-app/` (старая обёртка Capacitor) осталась в репозитории как
  история версии 1.0.0 и не собирается.
- При обновлении с 1.0.0 прогресс сбрасывается: он лежал в localStorage
  WebView, перенести его автоматически нельзя. Старый файл прогресса
  можно загрузить вручную на странице «Родителям».

## Сборка

```powershell
.\tools\build.ps1          # озвучка -> код -> тесты -> подписанный APK
```

APK: `android/app/build/outputs/apk/release/app-release.apk`
